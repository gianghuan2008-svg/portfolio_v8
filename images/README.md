
# PORTFOLIO V8

## 1. Giới thiệu

Portfolio V8 là website cá nhân dùng để giới thiệu thông tin,
kỹ năng, các dự án đã thực hiện và thông tin liên hệ.

## 2. Công nghệ sử dụng

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## 3. Demo

https://TEN-GITHUB.github.io/TEN-REPOSITORY/

## 4. Cách mở website

1. Mở trình duyệt Google Chrome.
2. Truy cập đường dẫn Demo ở trên.
3. Chờ website tải hoàn tất.
4. Kiểm tra nội dung, hình ảnh và giao diện.
5. Thử mở website trên điện thoại.

## 5. Cấu trúc thư mục

- index.html: Trang chủ.
- css/style.css: File định dạng giao diện.
- images/: Thư mục hình ảnh.
- docs/: Tài liệu minh chứng.
- CHANGELOG.md: Lịch sử thay đổi.
- AI_LOG.md: Nhật ký sử dụng AI.
